# auction-pdca（オークション代行 営業部門）

## これは何か

`assets/anken-kanri.csv` を単一の案件台帳として、セルメイトの**案件進行の記録**と**月次PDCA**を回す。
目標は月10台（手数料55,000円×10＝55万円）。数字はすべて台帳から算出し、記憶や推測で語らない。

## 案件台帳（assets/anken-kanri.csv）

カラム：`受付日 / 案件ID / 車種 / 年式 / 流入元（YouTube・LINE・リベシティ・紹介・その他）/
きっかけ動画 / 状態 / 相談内容の要約 / 見積提示額 / 成約日 / 落札額 / 手数料 / 入金日 /
失注理由 / 温度感メモ / 備考`

- 状態：`相談中 → 見積提示 → 成約 → 出品中 → 落札 → 引き渡し済み → 入金済み`（失注はどの段階からでも）
- **お客様の氏名・住所・電話番号は台帳に記録しない**。案件IDと車種で識別する
- 失注時は必ず失注理由を記録する（価格不満／他社流出／連絡途絶／時期尚早／エリア外／その他）
- 数字が不明なまま「たぶん」で埋めない。不明は空欄にして確認する

## 記録の受け取り方

- 「◯◯の相談が来た」「△△成約した」「××は流れた、理由は…」の報告文から台帳の行を作成・更新する
- LINEのやり取りの貼り付け・スクショからも読み取る（個人情報は転記しない）
- 更新のたびに、変更後の行と現在の月間進捗（成約◯台/目標10台）を短く提示する

## 月次PDCAレポート（「今月のPDCA」で出力）

1. **数字**：相談数→見積提示数→成約数のファネルと各転換率、成約合計額、手数料売上、目標対比（10台/55万円）
2. **流入元分析**：どのチャネル・どの動画が相談を生んだか（YouTube動画別に集計）
3. **失注分析**：理由別の件数。「対応を変えれば拾えたか」の振り返りと、次月の改善案1つ
4. **放置アラート**：状態が7日以上動いていない案件の一覧
5. **単価分析**：成約車種の傾向（高額車の比率）と、動画で扱うべき車種への示唆
   （channel-analytics のネタ選定と接続する）

改善案は毎月1つに絞る（あれもこれも変えない。効果検証ができなくなるため）。

## 部門ルール

- 売上・入金の数字は keiri-bumon（経理部門）の仕訳と月次で突き合わせる
- お客様への返信文の作成は reply-writer スキルに委譲する
- 相場の調査が必要な場合は usedcar-hyper-research スキルに委譲する
