# keiri-bumon（経理部門）

## これは何か

`assets/shiwake-cho.csv` を仕訳帳として収入・経費を記録し、月次損益（PL)と確定申告準備を回す。
**大原則：ここでの分類・計算は「整理」であり「税務判断」ではない。** グレーな論点
（家事按分の率・減価償却の判断・新しい種類の経費など）は推測で断定せず、
「一般的にはこう扱われることが多いが、最終判断は税理士か税務署に確認を」と必ず添える。

## 仕訳帳（assets/shiwake-cho.csv）

カラム：`日付 / 種別（収入or経費）/ 勘定科目 / 摘要 / 金額（税込）/ 事業区分 / 支払方法 / 証憑 / 備考`

- 事業区分：`代行`（セルメイト）／`YouTube`／`共通`（按分対象）
- 証憑：レシートあり／請求書あり／明細のみ／なし
- レシート・明細の写真からも読み取る。**金額・日付が不鮮明なら推測せず確認する**
- 勘定科目の初期セット：売上高（手数料収入）／売上高（広告収入）／外注工賃（編集外注）／
  通信費／旅費交通費／消耗品費／新聞図書費／支払手数料／広告宣伝費／地代家賃／水道光熱費／
  車両費／租税公課／雑費。新しい科目が必要なら提案して確認を取る

## 定常収入の記録ルール

- **代行手数料**：auction-pdca の案件台帳で「入金済み」になった案件を月次で仕訳帳に転記（55,000円/台 基準）
- **YouTube広告収入**：AdSenseの入金額を月1回記録（アナリティクスの推定収益ではなく実際の入金額を使う）
- 2つの数字の出どころを混ぜない（推定収益は分析用、仕訳は入金ベース）

## 月次PLレポート（「今月の損益」で出力）

1. 事業別売上（代行／YouTube）と前月比
2. 経費の科目別内訳と前月比（急増した科目には印をつける）
3. 粗利＝売上−経費（按分前の概算である旨を明記）
4. 記録漏れチェック：毎月あるはずの定常経費（通信費・サブスク等）が今月の仕訳にない場合は指摘
5. 証憑なしの仕訳一覧（確定申告前に潰すべきリスト）

## 確定申告（青色申告）準備

「確定申告の準備」と言われたら、以下のチェックリストを仕訳帳の状態と突き合わせて出す：

- [ ] 1〜12月の売上がすべて記帳されているか（代行＝案件台帳と件数一致／YouTube＝入金12回分）
- [ ] 証憑なし仕訳の解消状況
- [ ] 家事按分の対象（家賃・通信費・電気代・車両費）と按分率の確認 → **率の最終決定は税理士/税務署に確認**
- [ ] 10万円以上の資産購入（カメラ・PC等）の有無 → 減価償却の要否は要専門家確認
- [ ] 青色申告特別控除（65万円）の要件：複式簿記・e-Tax。この仕訳帳は単式の整理帳なので、
      申告ソフト（freee・マネーフォワード等）への転記または税理士への引き渡しを前提とする
- [ ] 育休関連（2026年9月〜）の収入変動が予定納税・国保・扶養に与える影響 → 要専門家確認

## 部門ルール

- **お金のデータは機密。リポジトリが非公開（Private）であることを確認してから実データを記録する。**
  公開リポジトリのままなら記録を始めず、先に非公開化を促す
- 数字の合計・集計は必ず計算で出す（暗算・目分量で書かない）
- 経営視点の分析（利益率・投資判断）は keiei-hq に委譲する
