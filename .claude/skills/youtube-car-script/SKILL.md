# youtube-car-script（ロング動画 台本自動生成）

## これは何か

「相場情報」「売却ノウハウ」「購入ノウハウ」のロング動画を週1本ペースで量産するための、
**台本＋投稿パッケージ（1ファイルのMarkdown）** を自動生成するスキル。動画そのものは作らない。
マサさんがカメラの前で読める完成台本と、タイトル・概要欄・ピン留めコメント・投稿設定チェックリストまでを一度に出す。

チャンネルの前提：視聴者は「車を売ろうか・買い替えようか考えている人」。全動画のゴールは
**LINE登録（無料相場診断）→ セルメイト（オークション代行）への導線**。動画単体の再生数より、
LINE登録につながる構成を常に優先する。

## 3つの動画タイプ

| タイプ | 内容 | 尺目安 | 役割 |
|---|---|---|---|
| 相場情報型 | ◯◯（車種）の買取相場・リセール解説 | 8〜12分 | ショートの関連動画の受け皿。検索流入の主砲 |
| 売却ノウハウ型 | 高く売る手順・ディーラー下取りの罠・一括査定の使い方 等 | 8〜12分 | 信頼構築とLINE誘導 |
| 購入ノウハウ型 | 値引き交渉・リセールで選ぶ車選び・見積書の見方 等 | 8〜15分 | 見積もりDB・ショートとの連携ネタ |

## 入力の受け取り方

1. **タイプ**（相場情報／売却ノウハウ／購入ノウハウ。依頼文から判断できれば聞き直さない）
2. **テーマ**（車種名 or ノウハウの題目）
3. 相場データ（任意）：オークション実績・見積もりDB（car-short-script の assets/mitsumori-database.csv）・
   マサさんが持つ実案件の数字
4. 紐付けたいショート動画（任意。相場情報型は対応ショートの「関連動画」の受け皿になるため、あれば必ず台本に反映）

「今週のロング」「次のロング作って」と言われたら、`assets/neta-cho.csv`（ネタ帳）の
状態＝未着手のうち優先度が最も高い行を選んで生成する。ネタ帳が空なら、見積もりDBの蓄積状況と
直近のショート計画から候補を3つ提案して選んでもらう。

### 数字に関する絶対ルール

- **相場・値引き・落札額などの金額は、マサさんが提供したデータか見積もりDBにある数字だけを使う。**
  相場をこちらで推測・生成して台本に書くことは絶対にしない（チャンネルの信頼が一発で崩れるため）。
- 数字が無い場合は、①マサさんに実データを質問する、②数字を使わない構成（手順・考え方中心）に切り替える、
  のどちらかを提案する。勝手にWeb上の相場を拾って断定的に書かない（使う場合は出典と取得日を台本に明記し、
  「あくまで参考値」とマサさんが言う前提の文言にする）。

## 台本の書き方ルール

- **話し言葉で書く。** マサさんがそのまま読める文章。1文は短く、体言止めと問いかけを織り交ぜる
- 冒頭15秒がすべて：結論やいちばん強い数字を**チラ見せ**してから自己紹介に入る（自己紹介から始めない）
- 自己紹介は1〜2文に固定：「車の売却専門家のマサです。オークション代行で年間◯台の売却をお手伝いしています」型
- 本編は3〜5個のブロックに分け、各ブロックの頭に「視聴者の疑問」を置いてから答える
- 各ブロックにBロール指示（映すもの：実車・書面・画面キャプチャ・テロップ図解）を[Bロール：〜]形式で添える
- 強調したい数字・結論には[テロップ：〜]指示を添える
- 中盤（40〜60%地点）に1回だけ軽いLINE言及：「概要欄のLINEから無料で相場診断もやってます」
- ラストのCTAは固定順序：①まとめ（結論の再提示）→②LINE誘導（無料相場診断）→③チャンネル登録→④関連動画の口頭誘導
- ショートと違い、ロングは「親切に全部見せる」。出し惜しみしない。信頼がLINE登録に変わる

## タイトル・サムネ文言

- タイトル案は毎回3本。型：「【◯◯年◯月】{車種}の買取相場、実データで公開」
  「{車種}を高く売る人が必ずやっている◯つのこと」「ディーラー下取りで{金額}損した実例」
- 検索を意識し、車種名・「相場」「買取」「下取り」「値引き」のいずれかをタイトル前半に入れる
- サムネ文言は最大13文字×2行まで。数字が入るなら数字を最大サイズに

## 出力仕様

`assets/daihon-template.md` を土台に、1本につき1ファイルのMarkdownを生成する。
ファイル名は `{テーマ}_long_daihon.md` を推奨。含めるセクション：

1. 動画情報（タイプ／尺目安／使用データと出典／紐付けショート）
2. タイトル案3本＋サムネ文言案
3. 台本本文（ブロック構成、Bロール・テロップ指示込み、読み上げ時間の目安付き）
4. 概要欄テンプレ（LINE導線URL枠・チャプター用タイムスタンプ枠・関連リンク）
5. ピン留めコメント案
6. 投稿設定チェックリスト
7. ネタ帳更新用の1行（生成後にネタ帳の該当行を「台本済み」に更新する内容）

## 投稿設定チェックリスト（毎回含める）

- [ ] 概要欄の先頭にLINE導線（LP→LINE。URLはマサさんの既存LPのもの。不明なら確認する）
- [ ] チャプター（タイムスタンプ）を概要欄に設定
- [ ] ピン留めコメントを設置（LINE誘導＋見積書・売却相談の募集文）
- [ ] 対応するショートが既に投稿済みなら、そのショートの「関連動画」に本動画を設定する
      （YouTube Studio → コンテンツ → 該当ショート → 詳細 → 関連動画）
- [ ] タグ：車種名・「買取」「相場」「売却」等を設定
- [ ] 終了画面に「次に見るべき関連ロング」を1本設定

## ネタ帳の運用（自動化ループの中核）

`assets/neta-cho.csv` がネタの待ち行列。カラム構成を勝手に変えない。

- 台本を生成したら該当行の状態を「未着手→台本済み」に更新する内容を出力の末尾に示す
- マサさんから「投稿した」「再生◯回だった」と報告があれば、投稿日・結果メモを追記する内容を示す
- 結果が良かったタイプ・車種は、次のネタ提案時に優先度を上げて提案する（この判断理由も一言添える）
- 見積もりDB（ショート側）に新しい車種のデータが貯まったら、その車種の相場情報型をネタ帳への追加候補として提案する
- ショート5本計画（ランクル300→ヴェルファイア→ハイエース→ヴォクシー→ライズ）の各車種には、
  関連動画の受け皿となる相場情報型ロングを必ず1本ずつ対応させる

## 週次の自動化フロー（推奨運用）

1. 週1回「今週のロング台本作って」→ ネタ帳の最優先1本の台本パッケージが出る
2. マサさんは撮影して投稿するだけ（編集指示は台本内のBロール・テロップ指示に従う）
3. 投稿報告→ネタ帳更新→翌週のネタ選定に反映、のループを回す
4. 定期実行（毎週月曜等）に載せる場合は、このスキルを呼ぶ一文をスケジュールに登録すれば良い
