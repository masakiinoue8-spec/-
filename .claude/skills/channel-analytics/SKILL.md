# channel-analytics（動画実績の分析と次の一手）

## これは何か

YouTube Studioのデータを `assets/douga-jisseki.csv`（動画実績DB）に蓄積し、
**「どの車種・どのタイプが取れるか」を数字で答え、ネタ帳の優先度更新案まで出す**分析スキル。
分析レポートは `assets/bunseki-report-template.md` の形式で出力する。

## データの受け取り方（3経路どれでも）

1. **YouTube Studioのエクスポート CSV**（推奨）：
   YouTube Studio → アナリティクス → 詳細モード → 右上のエクスポート → 「現在のビュー(.csv)」。
   期間は「全期間」、ディメンションは「動画」にしたものが最も使いやすい
2. **スクリーンショット**：Studioの「コンテンツ」一覧や動画別アナリティクスの画面キャプチャ。画像から読み取る
3. **手入力**：「◯◯の動画、3日で1.2万再生」のような報告文

いずれの場合も、読み取った数字を動画実績DBの行形式に整形して提示する。
**画像や報告文から数字が不鮮明・曖昧な場合は推測せず確認する。**

## 動画実績DB（assets/douga-jisseki.csv）

カラム：`公開日 / タイトル / 形式（ロングorショート）/ タイプ / 車種 / 再生回数 / 数字の取得日 /
インプレッション / CTR / 平均視聴維持率 / 平均視聴時間 / 登録者増 / LINE登録数 / 備考`

- 車種はタイトルから自動判定して埋める（判定できなければ空欄にして確認）
- タイプの分類：相場情報／売却ノウハウ／購入ノウハウ／見積もり公開（ショート）／その他
- 再生回数は伸び続けるため**「数字の取得日」を必ず記録**する。同じ動画の再測定は行を追加せず
  再生回数と取得日を更新し、大きな伸びがあれば備考にメモ
- LINE登録数は自動では取れない。マサさんがL Message側で流入元を確認できた場合のみ記入
- カラム構成を勝手に変えない

## 分析の観点（レポートに含めるもの）

1. **車種別ランキング**：車種ごとの平均再生・最高再生。「相場・売却系で伸びる車種」を特定する
2. **タイプ別比較**：相場情報型／売却ノウハウ型／購入ノウハウ型／見積もり公開の平均再生・維持率・登録者増
3. **形式別**：ショートとロングは土俵が違うため、**必ず分けて集計**し、混ぜた平均を出さない
4. **サムネ問題か中身問題かの切り分け**：
   - インプレッション多×CTR低 → サムネ・タイトルの問題
   - CTR高×維持率低 → 冒頭フック・構成の問題
   - インプレッション自体が少ない → テーマ選定（需要）の問題
5. **上位動画の共通点**：タイトルの型・数字の有無・車種・尺
6. **登録・LINEへの貢献**：再生数が多い動画と登録者増が多い動画は別物。両方のランキングを出す

## 分析の絶対ルール

- **DBにある数字だけで分析する。** 業界平均や「一般的なCTR」との比較を勝手に持ち出して断定しない
  （参考として言う場合は「一般論ですが」と明示する）
- データが少ない場合（例：車種あたり1本しかない）は、「傾向」ではなく「単発の結果」として扱い、
  本数が揃うまで断定を保留する旨をレポートに明記する
- ショートの再生回数とロングの再生回数を同列に比較して優劣を語らない

## 出力の最後に必ず含めるもの：次の一手

分析レポートの末尾に、以下を毎回つける：

1. **ネタ帳（youtube-car-script/assets/neta-cho.csv）の優先度更新案**：
   伸びている車種・タイプの順位を上げる提案と、その根拠（該当データ行）
2. **ショート計画への示唆**：見積もり公開ショートで次に扱うべき車種の提案
3. **確認したいこと**（あれば）：データの欠け・追加でエクスポートしてほしい期間や指標

更新案はマサさんの承認を得てからネタ帳CSVに反映する（勝手に書き換えない）。

## 定期運用（推奨）

- 週1回、週報のタイミングでStudioの数字を渡してもらい、DB更新→ミニ分析
- 月1回、全期間CSVをエクスポートしてもらい、フル分析レポート＋ネタ帳の優先度見直し
