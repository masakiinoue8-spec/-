# car-short-script

## これは何か

ジムニーノマドの見積もり公開ショート（25万回再生）で実証済みの「型」を、他車種へ横展開するための
**制作指示書（Markdown 1本）** を自動生成するスキル。動画そのものは作らない。撮影・編集チーム（またはマサさん自身）が
そのまま撮影・テロップ入れ・投稿設定に使える指示書を出力する。

**本スキルはショート動画（無音・テロップ主体・30〜40秒・9:16）専用。** ロング動画（車カルテ・リセール解説など）の
台本は `youtube-car-script` スキルの担当。「ショート」という語や60秒未満の縦動画の文脈がない依頼では起動しない。

## 核心コンセプト（絶対に崩さないルール）

このフォーマットの再生数は「見積書を1回で読み切れない」設計によるリプレイ誘発で成立している。指示書を作る際は
常にこの原則を守ること。

- **値引き額をズームや枠線で強調しない。** 親切に見せてしまうと1周で完結し、リプレイが起きない。
- **見積書シーンにはテロップを一切乗せない。** 書面自体が情報であり、視聴者が「探す」楽しみを邪魔しない。
- **動画内に「終わり感」テロップ（チャンネル登録・ロング誘導・次回予告等）を入れない。** ループが切れるとアルゴリズム評価が落ちる。
- カメラは見積書を「ギリギリ読めない速度」でなめる。速すぎても遅すぎてもリプレイが起きないので、
  指示書には必ず具体的な秒数レンジを明記する。

## 入力の受け取り方

ユーザー（マサさん）から次を受け取る。

1. **車種名**（必須）
2. **見積書の写真**（複数枚可。個人情報マスキング前でも構わない）
3. 本体値引き額・OP値引き額・総額（任意。写真から読み取れない場合の補完用）
4. 紐付けたいロング動画のタイトルまたはURL（任意。関連動画設定用）

### 車種名だけで写真が無い場合

指示書を仮生成せず、先に以下を質問すること（推測でテンプレを埋めない）。

- 見積書の写真（撮影予定で構いません、の一言を添える）
- 本体値引き額・OP値引き額・総額のいずれか
- グレード／契約時期（フックの煽り文言の方向性を決めるため）

### 見積書写真から金額・情報を読み取る際の必須ルール

- 写真に写っている金額・項目名は読み取って良いが、**文字が不鮮明・一部が隠れている・複数の解釈が可能な数字は
  絶対に推測で埋めない。** 「◯◯欄の数字が判読できませんでした。実際の金額を教えてください」とユーザーに確認する。
- 個人情報（氏名・住所・ディーラー名・担当者名・車台番号・電話番号など）は読み取れても、指示書の構成表やテロップ案には
  一切転記しない。マスキング箇所リストにのみ記載する。

## 出力仕様

出力は1本のショートにつき **1ファイルのMarkdown制作指示書**。雛形は `assets/shijisho-template.md` を土台にし、
以下6セクションを必ず含める。ファイル名は `{車種名}_shorts_shijisho.md` を推奨。

1. タイトル案 3本
2. 構成表（シーン番号／秒数／映像素材／テロップ／カメラワーク指示）
3. テロップ指示（文言・色・位置・表示秒数）
4. カメラワーク指示（見積書のどの範囲を・何秒で・どの順に流すか）
5. 投稿設定チェックリスト（関連動画・固定コメント・概要欄）
6. 個人情報マスキング箇所リスト（見積書写真から検出：氏名・住所・ディーラー名・担当者名・車台番号）

## 画面サイズとセーフゾーン

- キャンバス：9:16（1080×1920px）
- メーカー公式画像（16:9横長）は「拡大して左右クロップ」または「上下ぼかし背景」のどちらかを毎回指定する
- UIに隠れるゾーン：上部 約200px／下部 約500px／右端 約150px。テロップ・数字はこの外に置く
- テロップと読ませたい数字は **中央〜やや上の約880×1200px** に収める
- 見積書撮影時の注意を必ず指示書に書く：金額列を右端に置かない。書面はやや左寄せ、右に1〜2割の余白を残す

## テロップルール

- フォント：極太ゴシック（ラグランパンチ／けいふぉんと／源ノ角ゴシック Heavy 等）
- 縁取り：2重縁（白文字＋黒縁、または色文字＋白縁）
- 1画面1メッセージ、同時最大2行、1行最大13文字、幅は画面幅の8〜9割
- 色の役割は固定：**黄＝事実・車種名／赤＝感情・煽り／白＝中立情報**。3色まで、これ以外の色は使わない
- 冒頭フックは2秒固定で読み切れる文字数に収める
- 語尾は「...」で濁す（断定形にしない。未完了感を残す）
- 中盤の車両スライドには「問いのテロップ」（例：「値引きは...？」）を画面上部1/3に小さく1枚だけ入れる
- **見積書シーンはテロップなし**（例外を作らない）

## カメラワークルール

- 見積書は「諸費用欄 → オプション欄 → 総額ページ」の順で必ずなめる
- 各欄の滞在時間は「読めるか読めないかギリギリ」を狙う。目安：1欄あたり2.5〜4秒、金額が並ぶ行ほど遅めに設定する
- パンの方向・速度は指示書に具体的に書く（例：「上から下へ、3.5秒かけて等速でパン」）
- 総額ページで静止してカットを終える。誘導カットを足さない

## 構成テンプレート（30〜40秒想定）

| 秒数 | シーン | 内容 |
|---|---|---|
| 0〜2秒 | フック | 車両フロント画像＋黄テロップ（車種名＋「購入」）＋赤テロップ（感情ワード＋「...」） |
| 3〜12秒 | 車両紹介 | メーカー公式画像スライド3〜4枚（リア→内装→シート→リア 等）。中盤に問いテロップ1枚 |
| 12〜35秒 | 見積書実写 | 諸費用欄→オプション欄→総額ページの順に、読めるか読めないかの速度でカメラがなめる。テロップなし |
| ラスト | 終了 | 総額ページで静止→そのまま終了。誘導テロップなし、そのままループさせる |

指示書の構成表はこのテンプレートを基準に、車種・見積書の枚数に応じて秒数とシーン数を調整すること。

## 投稿設定チェックリスト（指示書に毎回含める）

- [ ] ショートの概要欄・固定コメントにURLを貼らない（2023年8月以降、ショートのリンクはクリック不可のため）
- [ ] **関連動画機能**に、対応するロング動画（リセール解説・車カルテ等）を設定する
      （YouTube Studio → コンテンツ → 該当ショート → 詳細 → 関連動画）
- [ ] **固定コメント**をリンクなしテキストで用意する。内容は次の3点を含める：
      1. 値引き額の答え合わせ
      2. 「◯◯は値引きよりリセールで差がつきます→『◯◯ リセール』で検索」の誘導文
      3. 見積書募集の一文：「あなたの最終見積もりも診断します。個人情報は隠してLINEから送ってください
         （プロフィールのリンクから）」
- [ ] 紐付けるロング動画のタイトル／URLが指定されていない場合は、投稿前にマサさんへ確認する一文を指示書に残す

## 見積書データベースへの記録

視聴者提供の見積書データは `assets/mitsumori-database.csv` の形式で蓄積する。指示書生成時、写真から読み取れた
情報（マスキング対象を除く）をこのCSVの1行分のデータとしてまとめ、指示書の末尾に「データベース追記用の1行」として
提示する。ユーザーが確認・修正してから実際のスプレッドシート／CSVに追記する運用とし、本スキールが直接ファイルを
上書き追記することはしない。将来的に「トヨタ全車種値引きデータベース」として一次ソース化する前提のため、
カラム構成を勝手に変更しない。

## 出力手順まとめ

1. 車種名・見積書写真（または補完情報）が揃っているか確認。足りなければ質問して止まる
2. 見積書から金額・項目を読み取る。不鮮明な箇所は推測せず質問する
3. 個人情報（氏名・住所・ディーラー名・担当者名・車台番号）を検出し、マスキング箇所リストに記録する
4. `assets/shijisho-template.md` を土台に、タイトル案・構成表・テロップ指示・カメラワーク指示・投稿設定
   チェックリスト・マスキング箇所リストを埋めた指示書を1ファイル生成する
5. 指示書の末尾に、データベース追記用の1行（CSV形式）を提示する
