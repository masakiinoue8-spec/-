## 4. カメラワーク指示（見積書実写パート詳細）

- 撮影時の書面レイアウト：金額列を右端に置かない。書面はやや左寄せ、右に1〜2割の余白を残す
- なめる順序：諸費用欄 → オプション欄 → 総額ページ（固定）
- 速度目安：1欄あたり2.5〜4秒。「読めるか読めないか」のギリギリを狙う。金額が並ぶ行はやや減速
- 総額ページで静止して撮影終了。値引き額へのズーム・枠強調は禁止
