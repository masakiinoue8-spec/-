# toukou-scheduler（月間投稿スケジュールと進行管理）

## これは何か

`assets/toukou-schedule.csv` を単一の進行表として、**月間スケジュールの自動生成**と
**1本ごとのステータス管理**を行う。マサさんの動作は「データを渡す」「撮影する」「編集する」
「予約投稿を押す」「済んだと報告する」だけ。それ以外（ネタ選定・データ整理・台本・タイトル案・
サムネ案・投稿設定チェックリスト・進捗の見える化）は全部こちら側の仕事。

## スケジュール生成のルール

「今月（来月）のスケジュール作って」と言われたら：

1. `youtube-car-script/assets/neta-cho.csv`（ネタ帳）から未投稿のネタを取る
2. **ロング**：**相場情報型を月12本、すべて比較動画形式**（2026-07-26 マサさん決定、
   単体解説は禁止）。1本＝2〜4車種のライバル対決・兄弟車対決・世代対決のいずれか。
   投稿枠は火・木・土の19時（新型車発売直後など話題性が強いときは曜日外の特別枠も可）。
   - 比較の組み方の型：①ライバル対決（例：ハリアーvsRAV4、ハイエースvsキャラバン）
     ②兄弟車対決（例：ヴォクシーvsノア、ジムニーvsジムニーシエラ）
     ③世代・グレード対決（例：ランクル300vs250、ガソリンvsハイブリッド）
     ④話題の新型車を軸にした3〜4台対決（例：新型エルグランドvsヴェルファイアHVvsアルファードHV）
   - 4台以上の大型比較を出したら、参加車種の中から2台を選んで**別角度の一騎打ち動画を
     続編として後日組む**（同じ車種でも切り口を変えれば重複にならない）
   - ノウハウ型は「隙間」枠＝5枠目や相場データが間に合わない回の差し替えとして月1〜2本。
     直近の比較ロングと車種を絡めて配置する
     （例：アルファードvsエルグランド比較の直後に残クレ検証→相互に関連動画で行き来させる）
   - 相場データは usedcar-hyper-research でこちらが自動調査するのが基本。
     調査ルール未定義の車種はマサさんにルール確認してからスキルに追加する
   - 撮影は週1回のまとめ撮り（3本/回）を推奨。台本パッケージは常に1週間先まで先行生成する
3. **ショート**：週1固定ではなく**新型車イベント駆動**（2026-07-26 マサさん決定）。
   新型車の発表・先行見積もり開始・発売・納車開始のタイミングで見積もり公開ショートを
   即制作・即投稿する（ジムニーノマド25万再生の再現）。目安は月2本、上限4本。
   - `assets/shinsha-watch.csv`（新型車ウォッチリスト）でイベント予定を管理し、
     スケジュール生成・週次確認のたびに直近イベントを確認する
   - 新型車ショートが伸びたら、その車種の相場解説ロングを**後追いで**翌週土曜に差し込む
     （ショートが先・ロングが受け皿になる逆パターンもOK）
   - ロングから切り出すノウハウショート（残クレ60秒など）は、新型車イベントがない週に
     余力があれば出すオプション扱い。義務にしない
4. channel-analytics の分析結果があれば、伸びている車種・タイプを優先配置する
5. 月の制作本数はロング12＋隙間1〜2＋ショート（イベント発生分）。2026-07-26にマサさんが
   月12本体制を決定済み。さらに増減する場合はマサさんに確認する
6. 生成したら `assets/toukou-schedule.csv` に行を追加し、月間カレンダー形式でも提示する

投稿曜日・時間のデフォルト：ロング＝土曜19時／ショート＝イベント発生から48時間以内の19時
（鮮度が命。曜日は問わない）。マサさんの指定があればそちらを使う。

## 半自動パイプライン（2026-07-26 マサさん決定の分業）

**マサさんがやるのは「撮影」「最終確認」「予約投稿ボタン」「データ提供（見積書・金利実例）」だけ。**
それ以外は全部こちらで自動生成する。1本ごとに以下の**投稿パッケージ**を
`assets/packages/YYYY-MM-DD-<slug>.md` として作成し、進行表の「台本ファイル」列に記録する。

投稿パッケージの標準構成（これが揃って初めて「台本済み」）：

1. **タイトル案3つ**（本命／検索最適化型／煽り強め）＋推奨1つ
2. **サムネイル案2つ**（文言・配色・構図・素材指示まで。マサさんは選ぶだけ）
3. **フル台本**（セクションごとに：ナレーション全文／画面に出すテロップ／Bロール・画面指示）
4. **資料セット**（相場データの整理表・計算結果・引用元。相場は usedcar-hyper-research、
   トレンドは research スキルで自動収集。見積書・金利実例だけマサさん提供）
5. **編集指示書**（カット構成・テロップ全リスト・強調色・SE/BGMの入れどころ。
   外注編集者にそのまま渡せる粒度＝編集8割）
6. **投稿設定セット**（概要欄・タグ・固定コメント・関連動画・終了画面の指定）

マサさんの最終確認で修正が入ったらパッケージを直して再push（勝手に公開しない）。

## 週次自動実行（Routine）

毎週月曜7時（JST）に「今週の投稿確認」が自動で走る：
①今週投稿予定と状態 ②データ待ちボトルネックの依頼リスト ③今週分パッケージの自動生成
④shinsha-watch.csv の直近イベント確認。Routineが止まっていたら再登録すること。

## ステータス管理（進行表のライフサイクル）

各行の状態は次の順に進む：

`ネタ確定 → データ待ち → 台本済み → 撮影済み → 編集済み → 投稿済み`

- **データ待ち**：相場情報型・見積もり公開はマサさんからのデータ（相場まとめ・見積書写真）が必要。
  データ不要なノウハウ型はこの状態をスキップして良い
- マサさんから「相場データ」「見積書の写真」が届いたら：
  1. 内容を読み取り整理する（不鮮明な数字は推測せず確認）
  2. 相場データは要点をまとめて該当行の台本の材料として記録、見積書は見積もりDBへの追記案を作る
  3. そのまま該当スキル（youtube-car-script / car-short-script）を呼んで台本・指示書を生成し、
     タイトル案・サムネ文言案まで一気に出す → 状態を「台本済み」に進める
- 「撮影した」「編集終わった」「投稿した」の報告で状態を進める。投稿済みになったら
  ネタ帳の該当行も更新し、投稿設定チェックリスト（関連動画・固定コメント）の実施を確認する
- 投稿済みの動画は channel-analytics の実績DBに行を作る（数字は後日取得）

## 「今週の投稿確認」で出すレポート

毎週の確認（定期実行推奨）で、以下を短くまとめる：

1. **今週投稿予定**：何を・いつ・現在の状態
2. **ボトルネック**：データ待ちで止まっているもの → マサさんに必要な物を具体的に依頼
   （例：「ランクル300の相場データがまだです。オークション実績の写真をください」）
3. **前倒しできるもの**：台本済みでまだ撮影していないもの一覧（撮影のまとめ録りを提案）
4. **遅延の扱い**：投稿予定日を過ぎたものはスケジュールを後ろにずらす案を提示（勝手に消さない）

## マサさんの動作（これだけ）

| タイミング | やること |
|---|---|
| 月初 | 「今月のスケジュール作って」→ 出てきた案をOK/修正 |
| データ準備 | 相場データ・見積書写真をチャットに貼る（まとめてでOK） |
| 撮影 | 台本パッケージを見ながら撮る → 「撮った」と報告 |
| 編集 | 台本内のBロール・テロップ指示に従う（外注編集者にそのまま渡せる形式）→「編集済み」と報告 |
| 投稿 | YouTube Studioで**予約投稿**を設定（スケジュールの日時どおり）→「投稿した」と報告 |

投稿のアップロード自体の自動化（YouTube APIのOAuth連携）は将来の拡張とし、現段階では
Studioの予約投稿機能で「投稿作業を週1回にまとめる」運用を推奨する。

## 進行表（assets/toukou-schedule.csv）

カラム：`投稿予定日 / 投稿時間 / 形式 / ネタ / 車種 / タイプ / 状態 / データ / 台本ファイル / ペア動画 / 備考`

- カラム構成を勝手に変えない
- 「データ」列は：不要／待ち／受領済み のいずれか
- 状態変更は必ずマサさんの報告か明示的な指示に基づく（勝手に進めない）
