# ノウハウ動画の演出プラン（2026年7月・マサさん確認済みの方向性）

ネタ帳優先度11〜15の動画化にあたってのアプローチメモ。台本生成時（youtube-car-script /
car-short-script）はこのプランを前提に作ること。

## 1. 残クレ動画 →「残クレしたらいくら損するかガチ検証」フォーマット

### 残クレ地獄の中身（動画で暴く仕組み）

1. **金利は「残価を含めた全額」にかかる**：月々が安く見えるのは元本を据え置いているだけで、
   据え置いた残価部分にも金利3〜6%が発生し続ける。総支払額は通常ローンより高くなりがち
2. **走行距離制限**（年1万〜1.5万km）超過で返却時に追加精算
3. **傷・へこみ・修復歴で残価保証が崩れる**：返却時に精算金を請求される
4. **中途解約は残債＋残価の一括返済**：事故で全損したら保険金で足りないケースも
5. **最終回に「乗り換えループ」へ誘導される構造**：ディーラー側は下取り車も新車販売も
   両方取れる。営業が残クレを執拗に勧めるのはノルマと利益構造のため（X炎上の核心）

### 検証動画の独自アプローチ（他チャンネルとの差別化）

- 車種は**アルファード**で固定（X炎上の題材そのもの＋自チャンネルの相場ネタと連動）
- 5年間の総支払額を4パターンで実額計算：①現金一括 ②銀行マイカーローン（金利2%前後）
  ③残クレ→返却 ④残クレ→最終回買取
- **ここが独自性**：⑤「銀行ローンで買って5年後に買取に出す」を、マサさんの強みである
  **実際の買取相場データ**で計算する。リセールの高い車は設定残価より実勢買取価格が
  高いことが多く、「返却＝差額をディーラーに献上」だと数字で示せる
- 結論は全否定にしない：「等級が低い若者」「初期費用が出せない人」など残クレが合理的な
  ケースも提示 → 信頼性が上がり炎上リスクも下がる
- サムネ・タイトル方向：「残クレで◯◯万円消えました【ガチ計算】」「ディーラーが残クレを
  勧める本当の理由」
- ショート切り出し：金額カウントアップ演出で「5年でこの差」だけ見せる60秒

## 2. ローン残債あり売却（再生が取れるかの見立て）

- バズ型ではなく**検索流入のストック型**。ガリバー・ネクステージ・カービュー等の大手が
  全社SEO記事を出している＝検索需要が恒常的にある証拠
- 検索する人は「今まさに売ろうとしている人」なので、再生数の絶対値より
  **LINE登録・代行成約への転換率が高い**ことを狙うネタ。1本出して実績DBで検証する
- 個別動画の再生回数データは外部からは取得できなかったため「確実に伸びる」とは断定しない

## 3. 一括査定の着信ラッシュ →「実験＋解決策」演出

### 演出（実験パート）

- **スマホ画面収録で申込→着信をリアルタイム風に見せる**：「申込10秒で1件目」
  「1時間で着信◯件」をカウンターテロップで積み上げる。顔出し不要で最も引きが強い絵
- 業者名・電話番号はモザイク処理（特定業者攻撃にしない。攻撃型は訴訟・削除リスク）
- 着信ラッシュ画面はそのままショートの素材になる（9/29ショートで使用）

### 解決策パート（5段階で提示）

1. カーセンサー：「メール連絡希望」欄が使える数少ない一括査定
2. MOTA：事前入札で上位3社しか電話してこない仕組み
3. ユーカーパック・楽天Car：オークション形式で窓口一本化
4. 断り方テンプレ：「他社で成約済みです」の一言でOK（トークをテロップで見せる）
5. **最終着地：電話が一切かかってこないオークション代行（セルメイト）** → 固定コメントと
   LINEへ誘導。宣伝色を出しすぎず「僕がやっている方法」として自然に置く

## 4. 諸費用ぼったくり・買い方動画（顔出しなしで飽きさせない工夫)

- **勝ちパターンは既に持っている**：ジムニーノマド見積もりショート25万再生＝
  「実物の見積書を映して赤ペンでツッコむ」フォーマット。これをロングに拡張する
- 演出の道具箱：
  - 実物見積書を手元撮影し、1行ずつ**赤ペン添削**（◯＝妥当／×＝カット交渉可）
  - 「代行費用」「納車費用」「車庫証明代行」など**払わなくていい項目リスト**を
    金額カウントダウンのテロップで積み上げ「合計◯万円削れます」
  - **クイズ形式**で掴む：「この見積書、◯万円盛られています。どこでしょう？」→
    冒頭30秒の視聴維持フック
  - Before/After：交渉前と交渉後の見積書を並べて差額を見せる
- 顔出しなし全般の原則：①手元＋実物書類 ②スマホ・PCの画面録画 ③図解スライド＋
  ナレーションの3種を1本の中でローテーションして画変わりを作る。1カット20秒以上
  同じ絵を続けない
