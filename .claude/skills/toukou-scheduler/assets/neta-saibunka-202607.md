# ノウハウネタ細分化企画書（2026年7月）

演出プラン（enshutsu-plan-202607.md）を、マサさんのチャンネルに合わせて1本単位まで
細分化したもの。台本生成時はこの企画書の該当ビートを構成のベースにする。

## チャンネル共通の「型」（全動画に適用）

- **フレーム統一**：「車は資産。売り方・買い方で数十万円変わる」— 30〜40代男性・
  資産管理視点のターゲットに全動画をこのメッセージで貫く
- **冒頭フックの型**：金額クイズ or 損失額の提示（「◯◯万円損してます」）を最初の15秒に置く
- **裏付けの型**：一般論で終わらせず、必ず「実際の買取相場データ」or「実物の見積書」で
  答え合わせする（他チャンネルにない武器）
- **締めの型**：行動チェックリスト（3つまで）→ 固定コメント・LINE誘導 → セルメイトは
  「僕がやってる方法」として1回だけ自然に触れる
- **顔出しなし画変わり**：手元実物／画面録画／図解スライドを20秒以内でローテーション

## シリーズA：残クレ大解剖（ロング3本＋ショート2本）

### A-1 残クレガチ検証（9/12投稿予定・フラッグシップ）

- タイトル案：
  1. 「【ガチ計算】アルファードを残クレで買うと◯◯万円消えます」
  2. 「ディーラーが残クレを勧める本当の理由を査定のプロが暴きます」
- フック：「月々3万9千円でアルファードに乗れます——この言葉の裏で、5年後に
  いくら払っているか計算したことありますか？」→ 金額クイズ
- 構成ビート：
  1. X炎上の紹介（残クレ地獄とは／営業が勧める構造）
  2. 仕組み図解：残価据え置き＝元本が減っていない／金利は全額にかかる
  3. ガチ計算：①現金一括 ②銀行ローン(約2%) ③残クレ返却 ④残クレ買取 の5年総額
  4. **答え合わせ**：5年落ちアルファードの実勢買取相場 vs 設定残価 →
     「返却は差額をディーラーに献上」を実データで証明
  5. 走行距離制限・傷精算・中途解約の落とし穴を補足
  6. 残クレがアリな人（等級が低い若者／初期費用ゼロで乗りたい人）
  7. チェックリスト：契約前に確認する3つの数字（実質金利・設定残価・総支払額）
- 必要データ：アルファード40系の新車価格・ディーラー残クレ金利・銀行ローン金利の実例、
  5年落ちアルファードの買取相場（**usedcar-hyper-research で調査可能**）
- ショート展開：A-S1「5年でこの差」金額カウントアップ60秒

### A-2 残クレ中の車、実は売れます（途中でやめる方法）

- タイトル案：「残クレの途中でも車は売れます【やめ方3ステップ】」
- フック：「残クレだからあと3年は乗り換えられない…それ、思い込みです」
- 構成ビート：残クレ中の名義の話 → 売却額＞残債なら差額が戻る → 精算の流れ →
  リセールが高い車なら「途中売却が最も得」なケースの実例計算 → 注意点
- シリーズBのローン残債売却と兄弟動画。相互に関連動画設定
- 必要データ：残クレ精算の実例（代行案件から出せると最強。なければ一般例で可）

### A-3 KINTO vs 残クレ vs 銀行ローン どれが得？（ネタ帳18と統合）

- タイトル案：「【2026年版】KINTO・残クレ・ローン・現金、損しない買い方はどれ？」
- フック：「同じアルファードでも、買い方だけで総額◯◯万円変わります」
- 構成ビート：4方式の総額比較表 → 各方式が向く人のマトリクス（年齢・等級・年間走行距離）
  → 資産管理視点の結論「リセールが高い車×銀行ローン×高く売る、が最強」
- A-1の続編として投稿。A-1が伸びたら優先度を上げる

## シリーズB：ローン残債・売却手順（ロング2本）

### B-1 ローンが残ってる車を売る完全手順

- タイトル案：「ローンが残ってる車、売れます【手順は3つだけ】」（検索キーワード直球）
- フック：「『ローン中だから売れない』で損してる人、めちゃくちゃ多いです」
- 構成ビート：
  1. 結論：売れる（条件は名義次第）
  2. 車検証の所有者欄の見方（実物を手元撮影）
  3. パターン別フローチャート図解：自分名義／ローン会社名義×査定額＞残債／＜残債
  4. 所有権解除の流れと必要書類（委任状・譲渡証明書・印鑑証明を実物で見せる）
  5. 失敗しない業者選び → 代行なら精算まで一括で任せられる話
- ストック型なので**サムネ・タイトルは検索最適化を最優先**（バズ狙いの煽りより
  「ローン 残ってる 車 売る」の検索意図一致）
- データ不要・前倒し撮影可

### B-2 残債あり売却のトラブル実例（ネタ帳14と接続）

- タイトル案：「車を売ったのにローンが残り続ける…実際にあったトラブル3選」
- 構成ビート：名義変更されない業者／入金前倒産／二重ローン → 見分け方チェックリスト
  → 悪徳業者の見分け方動画（ネタ帳14）へ接続

## シリーズC：一括査定・売り方の正解（ロング2本＋ショート1本）

### C-1 一括査定 着信実験（9/26投稿予定）

- タイトル案：
  1. 「【実験】車の一括査定に申し込んだら1時間で電話◯件きた」
  2. 「一括査定の電話ラッシュ、全部出たらこうなった」
- フック：申込ボタンを押す画面収録 → 10秒後に1件目の着信画面（冒頭5秒で見せる）
- 構成ビート：
  1. 実験：画面収録＋着信カウンターテロップ（業者名モザイク）
  2. なぜ鳴り止まないのか（送客ビジネスの仕組みを図解）
  3. 電話を減らす方法5選：カーセンサーのメール希望欄／MOTA方式／オークション形式／
     断り方テンプレ（LINE風テロップで再現）／そして「電話ゼロの方法」
  4. 着地：オークション代行＝申込〜売却まで窓口1つ → セルメイト・LINE
- 実験素材の注意：実申込は自分の電話番号で行い、録画後に各社へ丁寧に断りを入れる。
  特定業者を晒す編集にしない
- ショート展開：C-S1 着信ラッシュ画面そのまま60秒（9/29予定）

### C-2 下取り vs 買取 vs 代行 徹底比較（ネタ帳6・7と統合、9/5と連動）

- タイトル案：「同じ車で査定額◯◯万円差。下取り・買取・代行を本気で比較した」
- 構成ビート：同一車種の3ルート査定額比較（実例データ）→ 各ルートの構造図解
  （なぜ下取りは安いのか）→ 使い分けマトリクス → 高く売る人の準備（ネタ帳10を吸収）
- 必要データ：同一案件の下取り提示額と代行成約額の実例（セルメイト案件から）

## シリーズD：損しない買い方（ロング3本＋ショート1本）

### D-1 諸費用ぼったくり添削（実物赤ペン）

- タイトル案：
  1. 「【実物公開】中古車見積書、この◯項目は払わなくていいです」
  2. 「この見積書、◯万円盛られてます。どこか分かりますか？」
- フック：クイズ形式。実物見積書をバッと見せて「◯万円盛られてます」
- 構成ビート：
  1. 見積書の実物を手元撮影、1行ずつ赤ペン添削（◯＝妥当／△＝交渉可／×＝不要）
  2. 削れる項目の定番：納車費用（自分で取りに行く）／車庫証明代行（自分でやれば数千円）／
     希望ナンバー・コーティング・メンテパック等のオプション
  3. 金額カウントダウンテロップ「ここまでで −◯◯万円」
  4. 交渉の言い方テンプレ（そのまま使えるトーク）
  5. Before/After：交渉前後の見積書を並べる
- 必要データ：実際の中古車見積書（視聴者・知人提供 or 自身の取得分。個人情報はマスキング）
- ショート展開：D-S1 クイズ型「どこが盛られてる？」60秒 → ジムニーノマド25万再生の
  フォーマットを買い方版に横展開する試金石

### D-2 買ってはいけない中古車の特徴（ネタ帳19）

- タイトル案：「査定のプロが絶対に買わない中古車の特徴7選」
- 構成ビート：修復歴の見抜き方（実車の見るポイントを写真・図解で）／メーター改ざん／
  水没車のサイン → 現車確認チェックリスト配布（LINE特典にして登録導線に）
- **チェックリストPDFをLINE登録特典にする**＝ノウハウ型でLINE登録を最大化する仕掛け

### D-3 リセールで選ぶ車＋2026年ランキング（ネタ帳9・17と統合)

- タイトル案：「【2026年版】買った瞬間から得する車TOP10（リセールで選ぶ）」
- 構成ビート：リセール率の考え方（実質負担額＝購入額−売却額）→ TOP10ランキング
  （ジムニーシエラ120%など）→ 相場情報型の過去動画へ関連動画で接続 →
  「次に相場解説してほしい車」をコメントで募集（コメント促進）
- 自チャンネルの相場情報型と最も相性が良いハブ動画。終了画面から各車種相場動画へ流す
