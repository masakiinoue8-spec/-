# トレンド調査メモ（2026年7月実施）

ネタ帳（優先度11〜21）と2026年9月スケジュールの根拠となる調査結果。
次回スケジュール生成時にもこのメモを参照し、鮮度が落ちていたら再調査すること。

|---|---|---|

| 新車購入直後の下取り査定・下取りvs買取 | 「そのまま売って大丈夫？」系 | 既存ネタ（下取りで損する仕組み）を9/5に配置 |
| リセールバリューランキング | ジムニーシエラ残価率120%が話題。トヨタSUV・ミニバン強し | ランキングTOP10（優先度17）はショート向き |

## X（Twitter）で話題のテーマ

- **「残クレ地獄」**：アルファード購入時にディーラーが残クレを執拗に勧めてきた投稿が拡散。
  「残クレはディーラーの利益・ノルマのため」という反応多数 → 優先度11・9/12ロングに採用
- **一括査定の電話ラッシュ**：申込10秒で電話、数分で着信20件超という不満投稿が定番バズ。
  21時〜8時の電話禁止規制の話も → 優先度12・9/26ロング＋9/29ショートに採用。
  オークション代行（セルメイト）への強い導線になる

## インスタ・リール系の傾向

- 失敗談・注意喚起系（「買ってはいけない中古車」「諸費用ぼったくり」）は保存・共有されやすい
- テロップ主体の60秒縦動画と相性が良い → 見積もり公開ショートの既存フォーマットを
  「ノウハウ切り出しショート」（残クレの落とし穴60秒など）にも横展開する

## 検索需要が確認できた購入系キーワード

- 中古車 諸費用（本体価格を安くして諸費用で稼ぐ店への注意）→ 優先度15
- KINTO・カーリース 損か得か・残クレとの比較 → 優先度18
- 中古車 値引き交渉・失敗しないチェックポイント → 見積書の見方（優先度8）と連動
