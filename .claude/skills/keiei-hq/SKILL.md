# keiei-hq（経営統括・社長室）

## これは何か

各部署のデータを読んで**1枚の経営レポート**に統合し、「次の一手」を提案する。
マサさんの仕事は読んで決めるだけ（考えるのはAI、決めるのは人間）。

## 部署一覧（データの読み先）

| 部署 | スキル | データソース |
|---|---|---|
| 営業（セルメイト） | auction-pdca | assets/anken-kanri.csv |
| 経理 | keiri-bumon | assets/shiwake-cho.csv |
| YouTube制作 | toukou-scheduler | assets/toukou-schedule.csv |
| YouTube分析 | channel-analytics / youtube-analytics | assets/douga-jisseki.csv＋Studioエクスポート |
| 台本（ロング/ショート） | youtube-car-script / car-short-script | neta-cho.csv／mitsumori-database.csv |
| リサーチ | research / usedcar-hyper-research | 依頼ベース |
| 文章・広報 | reply-writer | 依頼ベース |

## 経営レポートの構成（週次・月次共通）

1. **結論3行**：今週（今月）いちばん大事なこと
2. **数字ダッシュボード**：
   - セルメイト：成約◯台/目標10台、相談数、手数料売上
   - YouTube：投稿本数（予定対比）、再生・登録の動き、収益
   - 経理：月次売上・経費・粗利（記帳ベース）
3. **各部署の状況**：進んだこと／止まっていること（ボトルネックは名指しで）
4. **部署間の接続チェック**：
   - 伸びた動画 → 相談につながっているか（動画別流入）
   - 成約車種 → 次の動画ネタに反映されているか
   - 入金 → 仕訳に記帳されているか
5. **次の一手**：提案は最大3つ、優先順位つき。それぞれ「なぜ今か」を1行で
6. **マサさんへの質問**（あれば。決裁が必要なものだけ）

## レポートのルール

- **各CSVにあるデータだけで語る。** データが無い部署は「データ未入力」と正直に書き、
  埋めるために何が必要かを添える（無いものを推測で埋めてレポートの見た目を整えない）
- 目標対比は常に「月10台・55万円」（変更はマサさんの明示指示のみ）
- 育休制約（2026年9月〜、月80時間）を提案の前提に入れる。工数を増やす提案をする場合は
  何を削るかをセットで示す
- 週次は短く（読むのに2分以内）、月次は分析を深く
- 財務数字を含むレポートはチャット・ファイル渡しのみ。リポジトリが公開設定の間はコミットしない

## 定期運用（推奨）

- 週次：毎週月曜「週報出して」→ 2分で読める進捗＋ボトルネック
- 月次：月初「月次の経営会議」→ フルレポート＋翌月のスケジュール・ネタ優先度の更新案
