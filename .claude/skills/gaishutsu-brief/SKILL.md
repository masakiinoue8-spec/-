# gaishutsu-brief（外出先ブリーフ）

## これは何か

toukou-scheduler の進行表を軸に、外出中でもスマホで状況把握と発信ができるようにする
朝の定期ブリーフ。生成物は2つ：
1. **チャットメッセージ**（この会話に届く、読むだけで完結する短い要約）
2. **Artifactページ**（同じURLを毎回更新。ブックマークして開けば常に最新版）

投稿の中身（台本・サムネ案）は作らない。それは toukou-scheduler の投稿パッケージの仕事。
このスキルは「今どういう状態か」と「今日発信できる一言」を作ることに専念する。

## 作る内容

1. **今日やるべきこと**：`toukou-scheduler/assets/toukou-schedule.csv` から今日の日付の行を見る。
   状態が「日程仮」「待ち」のままなら、何が止まっているか（グレード情報待ち・相場データ待ち等）を
   明記し、今日中にマサさんが動けば解消するものを優先して示す
2. **今週・来週の投稿予定**：直近7〜10日分を日付順に一覧
3. **来月の動き**：翌月に日程仮・候補として積んである企画を3〜5件プレビュー
4. **車の最新ニュース**：WebSearchで「中古車 買取 相場 ニュース」「新型車 発表」などを調べ、
   直近1週間以内の動きに絞る。特に**ネタ帳・進行表に載っている車種に関係するニュース**
   （モデルチェンジ発表、価格改定、生産終了など）は最優先で拾う
5. **国内イベント**：直近2週間で開催される自動車関連イベント・展示会・カーミーティングを
   WebSearchで調べる。**撮影に行ける可能性があるイベント**（2026-09-26 マサさん決定）は
   見つけ次第、以下をセットで調べて「🎥 撮影候補」として目立たせる（events内でも最上段に置く。
   開催が数日以内に迫っている場合はニュースより上、alertの直下に出す）：
   - 開催日時（開始・終了時刻）
   - 会場名・住所
   - アクセス（最寄り駅・所要時間）
   - 入場料（前売・当日・年齢区分）
   - 一言で「何が撮れそうか」（来場者インタビュー向き／展示車の相場ネタに使える／等）
   詳細が薄い（イベント名だけ）場合は、日付だけ出して「詳細は次回までに調べる」と明記する
6. **海外の車イベント・新型情報**：海外モーターショー・新型車の発表スケジュールを調べる
7. **発信文の下書き**：4〜6で拾った中から一番旬なネタを1つ選び、
   - **YouTubeコミュニティ投稿文**（1〜3文、絵文字は控えめ、LINEやチャンネルへの誘導は入れない）
   - **つぶやき（X）案**（140字以内）
   をそれぞれ1本ずつドラフトする。マサさんはコピペして貼るだけにする
   （投稿API連携は無いため、自動投稿はしない。下書きを渡すところまでが役割）

## 実行手順

1. `toukou-scheduler/assets/toukou-schedule.csv` と `youtube-car-script/assets/neta-cho.csv`、
   `toukou-scheduler/assets/shinsha-watch.csv` を読む
2. WebSearchで上記4〜6を調べる（クエリの年月は必ずその日の日付に合わせる）
3. 内容を組み立て、Artifactとして公開する（初回は新規publish、以降は同じURLに再publishして更新）
4. 同じ内容を短くまとめてチャットメッセージでも送る（Artifactのリンクを添える）
5. 進行表の状態は絶対に自動で変更しない（報告に基づいてのみ更新するのがtoukou-schedulerのルール）

## Routine（毎朝自動）

`create_trigger` で自己宛て（persistent session）の日次Routineを登録し、cron は
**JST 7:00 = UTC 22:00（前日）** に設定する（`0 22 * * *`）。プロンプトは
「gaishutsu-briefスキルで今日の外出先ブリーフを作って」のように、このスキルを呼び出す
一文にする。Routineが無効化・削除されていたら、マサさんに一言確認してから再登録する。
